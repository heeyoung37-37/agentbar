Codex와 Claude Code의 주간 잔여량을 두 줄로 보여주는 첫 AgentBar 릴리스입니다.

- 이름 / 잔여 퍼센트 / 막대 정렬, 숫자 자릿수가 바뀌어도 고정 간격
- 주간 막대의 W 생략, macOS 기본 단색 표시
- 상세 화면 기본 색상 유지
- Claude 비용 차트도 최근 30일 날짜 칸 유지

**다운로드:** `AgentBar-0.1.0-macos-arm64.zip` · Apple Silicon(M1 이상) · macOS 14 이상

압축 해제 → AgentBar.app을 응용 프로그램 폴더로 이동 → 기존 CodexBar를 종료 → `Apply AgentBar Preset.command` 실행 → AgentBar 실행 후 본인 계정 연결.

CodexBar v0.76.0 기반 비공식 수정판입니다. 자체 서명(ad-hoc)이며 Apple 공증은 받지 않았습니다. 기존 CodexBar와 설정·식별자를 공유하므로 동시에 실행하지 마세요. 프리셋은 기존 표시 설정을 덮어씁니다. 계정·쿠키·개인 사용 기록은 포함하지 않았으며 자동 업데이트는 꺼져 있습니다.

설치 파일 검증용 `SHA256SUMS`를 함께 제공합니다. 고정된 원본 커밋, 수정 패치, 소스 재구성 및 빌드 스크립트는 저장소에 있습니다.
