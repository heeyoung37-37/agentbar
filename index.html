Features

Aligned names, percentages, and bars

A fixed percentage column and monospaced digits keep both rows aligned, from 100% to single-digit values.

Monochrome menu bar

Weekly bars omit the W label and use the macOS monochrome style. Existing provider colors remain in the detail view.

30-day cost chart

The Claude chart retains daily slots. Unused days become zero only after a full scan; unknown records remain distinct.

  1. 01

    Move the app

    Extract the ZIP and move AgentBar.app to Applications.

  2. 02

    Quit existing instances

    Quit CodexBar or AgentBar. They share settings and app identifiers.

  3. 03

    Apply the preset

    Run the included Apply AgentBar Preset.command. It overwrites display settings and enables both providers.

  4. 04

    Connect your accounts

    Open the app and connect your own Codex and Claude accounts. No login information is included.

First launch and macOS permissions

This release is not notarized by Apple. Verify the download source and checksum, then review any launch restriction in System Settings → Privacy & Security. Browser sessions may require your own login and macOS permissions.

CodexBar compatibility and updates

Do not run alongside CodexBar. Settings and app identifiers are shared, and the preset overwrites display preferences. Automatic updates are disabled; install new versions manually from GitHub Releases.

Source and build

AgentBar applies a patch to a pinned CodexBar v0.76.0 commit. See the build guide. Xcode, Swift 6.2+, and Python 3 are required. Internal binaries and some settings retain the CodexBar name.
