  1. 01

    다운로드하고 옮기기

    ZIP 압축을 풀고 AgentBar.app을 응용 프로그램 폴더로 옮기세요.

  2. 02

    기존 앱 종료하기

    설정과 앱 식별자를 공유합니다. 기존 CodexBar 또는 AgentBar를 종료하세요.

  3. 03

    표시 프리셋 적용하기

    동봉된 Apply AgentBar Preset.command를 실행하세요. 기존 표시 설정을 덮어쓰고 두 제공자를 활성화합니다.

  4. 04

    내 계정 연결하기

    AgentBar를 열고 본인의 Codex·Claude 계정을 연결하세요. 로그인 정보는 포함되어 있지 않습니다.

첫 실행이 차단되면 어떻게 하나요?

이 릴리스는 Apple 공증을 받지 않았습니다. 다운로드 출처와 체크섬을 확인한 뒤, 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 실행 여부를 직접 확인하세요. 브라우저 세션을 사용하는 경우 본인의 로그인과 macOS 권한 설정이 필요할 수 있습니다.

기존 CodexBar와 함께 사용할 수 있나요?

동시에 실행하지 마세요. AgentBar는 CodexBar와 설정·앱 식별자를 공유합니다. 프리셋은 기존 표시 설정을 덮어쓰지만 로그인 정보를 제공하지 않습니다. 자동 업데이트는 꺼져 있으며 새 버전은 GitHub Releases에서 수동 설치합니다.

소스와 빌드 방법은 어디에 있나요?

CodexBar v0.76.0의 고정 커밋에 수정 패치를 적용하는 방식입니다. 개발 문서에서 소스 재구성과 빌드 방법을 확인하세요. Xcode, Swift 6.2 이상, Python 3가 필요합니다. 내부 실행 파일과 일부 설정 화면에는 CodexBar 이름이 남아 있습니다.
